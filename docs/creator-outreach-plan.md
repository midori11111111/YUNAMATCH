## 送信順

1. 各サービスにつきA候補1名へ、公開前のクローズド体験依頼を送る。
2. 48〜72時間待つ。返信がなければ同サービスの次候補へ送る。
3. 同一文面の一斉送信はせず、その人の直近コンテンツを1件だけ具体的に記載する。
4. 無償紹介を当然視しない。紹介条件、PR表記、謝礼、修正希望の有無を相手に確認する。
5. 未承認ゲームや未公開機能を「公式」「許可済み」と説明しない。

## 最初の依頼文（DM向け）

```text
突然のご連絡失礼します。ゲーム仲間を、ランク・役割・遊べる時間から探せる非公式サービス「〇〇」を個人開発しています。

〇〇さんの［直近の具体的な動画・配信］を拝見し、普段そのゲームを遊んでいる方の目線で、公開前版を一度試していただけないかと思いご連絡しました。

お願いしたいのは、まず10〜15分ほど触っていただき、「実際に仲間を探せそうか」「危ない・分かりにくい所がないか」を教えていただくことです。紹介投稿は必須ではありません。

・サービスURL：［限定URL］
・運営と安全方針：［規約・安全センターURL］
・通報、ブロック、退会、未成年者の性別非表示に対応済み
・ゲーム運営会社の公式サービスではありません

もし紹介をご検討いただける場合は、条件やPR表記を含めて先にご相談させてください。ご興味がなければ返信は不要です。
```

ゲーム仲間をランク・役割・時間帯から探せる非公式コミュニティサービス「〇〇」を個人で開発しております。
所属の〇〇様に、公開前版の操作確認とフィードバックをご相談したくご連絡しました。

現段階では紹介を必須とする依頼ではなく、10〜15分程度の体験と、安全性・分かりやすさに関するご意見をお願いしたいと考えています。広告・紹介をご相談する場合は、費用、PR表記、掲載内容、修正確認を事前に合意します。

サービス概要：［URL］

ご検討いただける場合、条件と進行方法をご教示ください。

## 判断基準

- 最優先: ゲーム特化度、直近30日の活動、参加型企画との相性、問い合わせ窓口の明示
- 次点: Xフォロワー3,000以上、平均再生、投稿への反応
- 除外: 連絡窓口なし、直近活動なし、誹謗中傷・規約違反を主軸にするアカウント、未成年者への不適切な接触リスクがあるアカウント
