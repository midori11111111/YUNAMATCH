# 電気通信事業の変更確認用メモ

最終更新: 2026-08-26

既存の電気通信事業届出に対して、バロマッチ、スタメイト、荘園メイトの追加が変更報告等の対象になるかを所管総合通信局へ確認するための文面。

## 問い合わせ文案

```text
件名: 届出済み電気通信事業へのサービス追加に関する確認

電気通信事業担当者様

個人で運営するゲーム仲間募集サービスについて、電気通信事業の届出を提出済みです。
現在のサービスに加え、同じ運営者・同じシステム基盤上で、対象ゲームだけが異なる以下の3サービスを追加する予定です。

・バロマッチ（VALORANTのゲーム仲間募集）
・スタメイト（ブロスタのゲーム仲間募集）
・荘園メイト（第五人格のゲーム仲間募集）

各サービスはプロフィール、検索、募集、相互マッチ、利用者間チャット、通報・ブロックを提供します。恋愛・異性交際目的は禁止し、通常の個別チャットを運営者が自由に閲覧する機能は設けず、通報された範囲のみ安全確認に利用します。

確認したい事項は以下です。
1. 上記サービス名・URL・対象ゲームの追加は、既存届出の変更報告または新たな届出の対象になりますか。
2. 同一基盤・同一提供者でも、ドメインまたはサービス名称ごとに記載が必要ですか。
3. 追加前に提出すべき様式、期限、添付資料があればご教示ください。

既存届出の届出番号:
提供者氏名:
現在のサービス名・URL:
追加予定URL:
公開予定日:

よろしくお願いいたします。
```

## 送信前に埋める項目

- 既存届出番号と提出日
- 所管総合通信局
- 各サービスの確定ドメイン
- チャットの提供主体とデータ保存地域
- 公開予定日
- 回答者、回答日、回答内容の保存場所
