# 電気通信事業・3サービス追加判断記録

最終更新: 2026-08-26

これは運営上の確認記録であり、個別の法的助言ではない。最終判断は、現在の届出書一式と実装内容を管轄の総合通信局へ示して確認する。

## 条文上の確認点

- 電気通信事業法第16条第2項は、届出事項のうち同条第1項第1号、第2号または第5号に変更があった場合、遅滞なく変更を届け出ることを定める。
- 電気通信事業法施行規則第10条は、電気通信役務を記載した書類に変更があった場合の報告を定める。
- 同条の報告では、様式第10、変更後の様式第4、必要な場合はネットワーク構成図を提出する。

## 今回照合する変更

|項目|既存YUNAMATCH|追加後|差分確認|
|---|---|---|---|
|サービス名称|YUNAMATCH|バロマッチ、スタメイト、荘園メイトを追加|名称が届出書・添付書類の記載事項か確認|
|URL|yunamatch.com|サービス別URLまたはサブドメインを追加|URLが届出書・添付書類の記載事項か確認|
|役務|プロフィール、検索、募集、マッチ、個別チャット|同じ機能をゲーム別に提供|様式第4の役務区分・説明が変わるか確認|
|利用者|日本国内のゲーム利用者|対象ゲームが異なる利用者を追加|業務区域または提供条件が変わるか確認|
|設備|Vercel、Cloudflare、D1、R2|共通基盤を継続|構成図の変更有無を確認|
|通信の取扱い|通常DMは運営者が自由閲覧せず、通報範囲のみ確認|同じ|通信の秘密に関する運用を維持|

## 管轄局へ伝える内容

1. 既存の届出番号、届出者名、提出日
2. 同一運営者・同一基盤で3つのゲーム別サービスを追加すること
3. 各サービスがプロフィール、検索、募集、相互マッチ、個別チャット、通報、ブロックを提供すること
4. 恋愛・異性交際目的を禁止し、通常DMを管理者が自由閲覧しないこと
5. サービス名・URL・対象ゲーム追加について、変更届または施行規則第10条の報告が必要か
6. 必要な様式、添付書類、提出期限、提出先

送信用文面は `docs/telecom-change-inquiry.md` を使用する。

## 完了の証拠

次の全てが揃うまで `TELECOM_SERVICES_CONFIRMED=true` にしない。

- 管轄局名、担当部署、確認日、確認方法
- 回答メール、受付番号、電話確認メモのいずれか
- 届出・報告が必要な場合は提出書類の控えと受付記録
- 不要との回答の場合は、その前提となった説明内容と回答記録
- 管理画面に設定する証跡参照番号 `TELECOM_CONFIRMATION_REFERENCE`
