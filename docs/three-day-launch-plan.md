# 3サービス・3日公開計画

## 完了条件

- バロマッチ、スタメイト、荘園メイトで登録・検索・いいね・マッチ・募集・チャット・通報・ブロック・退会が動く
- 3サービスを運営画面から検索・停止・復旧・削除・通報確認できる
- サービス別の利用条件、プライバシーポリシー、問い合わせ先を公開する
- 本番URL、公式X、公式Discord、障害時の連絡手順を確定する
- スマホ実機と複数アカウントで公開前テストを終える
- 発信者への依頼文と送信対象を確定し、公開後に送信できる状態にする

## 1日目 — サイトを完成状態に固定

- [x] 3サービスのデータを完全分離
- [x] 登録から退会までのE2Eテスト
- [x] 通報・ブロック・アカウント停止・削除
- [x] サービス横断の管理者画面
- [x] 法務文面とインシデント対応手順
- [x] 公式アカウント案、発信者候補、依頼文
- [x] 本番用環境変数と秘密情報の棚卸し
- [x] DBバックアップと復元テスト
- [x] 負荷試験と主要APIのレート制限確認

## 2日目 — 外部設定と実機確認

- [ ] Riot申請情報とバロマッチ表記を最終確認
- [ ] NetEaseの回答待ち範囲と、未回答時の非公開範囲を確定
- [ ] Supercellファンコンテンツ表記を最終確認
- [ ] 公式Xを3サービス分用意
- [ ] 公式Discordを3サービス分用意し、通報・告知・募集導線を確認
- [ ] iPhone / Android / PCで新規登録、再ログイン、チャット、退会を確認
- [ ] OAuthのコールバックURL、Cookie、独自ドメインを確認

管理画面の「公開準備チェック」は、サービス別の本番URL・公式X・公式Discord・権利確認と、共通の認証・管理・メール・電気通信事業確認を表示する。秘密情報の値自体は表示しない。

## 3日目 — 段階公開

- [ ] 本番DBマイグレーションと直前バックアップ
- [ ] まず限定ユーザーで公開し、エラー率・遅延・通報を監視
- [ ] 問題がなければ一般公開へ切り替え
- [ ] 公式XとDiscordで公開告知
- [ ] 発信者へサービス別の依頼文を送付
- [ ] 公開後1時間、3時間、24時間で障害・負荷・離脱を確認

## 外部審査が3日以内に終わらない場合

- バロマッチはRiotの許可範囲を超える機能を公開しない
- 荘園メイトはNetEase回答前は限定プレビューに留める
- スタメイトはSupercellのファンコンテンツポリシー表示を維持する
- 審査待ちはサイトの未完成扱いではなく、公開範囲を制限した状態として管理する

## 公開停止ライン

- 他サービスのユーザーデータが混ざる
- ブロックした相手からメッセージが届く
- 管理者以外が通報内容や個人情報を閲覧できる
- 退会後も公開プロフィールが検索に残る
- 重大な利用規約・権利表記の不足が判明する
