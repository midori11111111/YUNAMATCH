# 3ゲーム開発チャット分岐チェックリスト

対象：スタメイト（ブロスタ）、荘園メイト（第五人格）、バロマッチ（VALORANT）

この文書を3つの開発チャットの共通基準とする。共通基盤はこのリポジトリで一度だけ変更し、各チャットはゲーム固有の表示・データ・外部審査だけを担当する。

## 各開発チャットの作業ルール

1. 最初にこの文書と `docs/three-game-launch-roadmap.md` を読む。
2. 共通APIやDBをゲーム専用に複製しない。変更が必要なら3サービスでテストする。
3. 公式画像・ロゴ・ゲーム内素材は、権利範囲が確認できるまで追加しない。
4. 外部への申請、投稿、連絡、一般公開はユーザーの最終確認後に行う。
5. 実装後は `npm test` と `npm run test:e2e` を通す。
6. 完了時に「実装済み」「手動確認待ち」「外部回答待ち」を分けて報告する。

## 現時点の公開順

1. スタメイト：方針表示を確定後、限定ベータ
2. バロマッチ：Riot審査範囲を確認後、限定ベータ
3. 荘園メイト：NetEase回答後、限定ベータ
