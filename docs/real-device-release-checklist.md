## 公開前の管理者確認

- [ ] 管理者画面で3サービスの利用者検索・停止・復旧・削除ができる
- [ ] 通報解決、停止、復旧、削除の操作ログが残る
- [ ] 本番DBの直前バックアップを保存し、復元手順を確認した
- [ ] 問い合わせメールが運営宛てに届き、送信先アドレスが利用者に露出しない
- [ ] 公式X・公式Discord・本番URLを管理画面の公開準備チェックで確認した
- [ ] 電気通信事業の追加サービス確認番号を管理画面へ設定した
- [ ] 各ゲームの公開根拠と証跡参照番号を管理画面へ設定した

## 公開停止条件

- 他サービスのプロフィール、募集、チャットが混ざる
- ブロック済み利用者からメッセージや申請が届く
- 管理者以外が通報本文・個人情報を閲覧できる
- 通常DMを管理者が任意に閲覧できる
- 退会後の公開プロフィールが残る
- 規約同意前に登録・チャットが使える
- 重大な権利表記、届出、未成年者保護の不足が判明する
